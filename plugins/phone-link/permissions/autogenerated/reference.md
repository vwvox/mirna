## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-get-status`
- `allow-start-pairing`
- `allow-cancel-pairing`
- `allow-list-phones`
- `allow-remove-phone`
- `allow-list-inbox`
- `allow-update-recording`
- `allow-list-linked-notes`
- `allow-publish-notes`
- `allow-export-logs`
- `allow-publish-courses`
- `allow-export-clips`
- `allow-list-reviews`
- `allow-remove-review`
